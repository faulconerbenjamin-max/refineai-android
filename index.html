Android · on-device · sideload

An AI toolbar for Android that runs on your phone — offline.

RefineAI adds a small floating toolbar over any app for quick replies, dictation and translation. The core features run on-device. It never presses Send for you.

Straight up: RefineAI is Android-only, it is not on Google Play yet, and you install it yourself. The download is about 1.3 GB because the language models ship inside the app. Below is exactly what it does, what it needs, and what uses the network — no "100% private" hand-waving.

What it actually does

Reply assist

Write in your messaging app, tap the cube, a reply is prepared in the text box. You review and press Send yourself. No auto-send.

Dictation

Speak and insert text into the field you're in — transcribed on-device.

Translation

On-device translation for messages and text, with downloadable language packs for higher accuracy.

One toolbar, any app

A floating pill over whatever app you're using — messages, maps, notes.

What uses the network (and what doesn't)

  • On-device: reply generation, dictation and the core translation run locally on the phone. The models ship in the app.
  • Needs network: downloading the app, one-time language/model packs, updates, and (if enabled) optional web search in Chat.
  • No RefineAI cloud inference: messages and audio are not sent to RefineAI servers to be processed, because RefineAI operates no such server.

Honest caveat: some optional features (an optional ~3.65 GiB high-accuracy translation model, or optional web search) use the internet when you turn them on. Payment is handled by Stripe.

What it needs before it works

  • Android 8.0+ (minSdk 26). Some optional AI features depend on the phone model.
  • Accessibility permission + "Allow restricted settings" — a one-time setup step. This is the most-abused Android permission, so here's why it's needed: it's how the floating toolbar reads the text on screen to help you reply. It cannot be enabled silently, and Android will make you confirm with your PIN/fingerprint.
  • ~1.3 GB download and some free storage.
  • No account, no sign-up.

We tell you this before you pay, on purpose. If that install ritual is a dealbreaker, don't buy it.
